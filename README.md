
# Amazon India Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze Amazon India sales performance and generate meaningful business insights.

The project focuses on sales, profit, product performance, order status, payment methods, fulfillment methods, and geographic performance.

## Tools & Technologies
- Power BI Desktop
- Microsoft Excel
- DAX
- Data Visualization
- Data Analysis

## Dashboard Pages

### 1. Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin
- Monthly Sales and Profit Trends

### 2. Sales Breakdown
- Sales by State
- Sales by Category
- Profit by Category
- Units Sold by Category
- Returns and Cancellations by Category
- Order Status Analysis
- Orders by Payment Method
- Top 10 Products by Sales

### 3. Business Insights
- State-wise sales performance
- Category-wise performance
- Order status analysis
- Payment method insights
- Top-performing products
- Business recommendations

### 4. Payment & Fulfillment Analysis
- Sales and Profit by Payment Method
- Sales and Profit by Fulfillment Method
- Profit by State
- Orders by State
- Return Rate
- Cancellation Rate

## Key Business Insights
- Maharashtra is the leading state in sales and profit.
- Electronics & Mobiles is the highest-performing category.
- UPI contributes the largest share of sales among payment methods.
- Amazon (FBA) is the leading fulfillment method by sales.
- Delivered orders account for 81.47% of total orders.
- Return rate: 4.85%.
- Cancellation rate: 5.00%.
